## ── 使用建议

| 工具 | 推荐设置 |
|------|---------|
| **Midjourney** | `/imagine` + prompt，加 `--ar 1:1`（图标）或 `--ar 16:9`（面板），`--v 6 --style raw` |
| **Stable Diffusion** | 模型推荐 `DreamShaper XL` 或 `CounterfeitXL`，CFG=7, Steps=30 |
| **DALL·E 3** | 直接粘贴 prompt，要求 "transparent background PNG" |
| **Adobe Firefly** | 使用 Reference Image 功能保持风格统一 |

### 替换到游戏中

生成的 PNG 文件放入 `assets/ui/` 文件夹，在 `game.js` 中：

```javascript
// 替换程序化绘制为真实素材示例
const imgHpBar = new Image();
imgHpBar.src = 'assets/ui/hp-bar.png';

// 在 drawHUD() 中替换对应 ctx 绘制调用：
ctx.drawImage(imgHpBar, bx - 4, by - 4, bw + 8, bh + 8);
```
