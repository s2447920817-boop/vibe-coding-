# 修仙地牢 · 炼道斩妖录

一款纯前端的修仙题材 Roguelike 地牢小游戏。无需安装、无依赖，打开网页直接玩。

## 在线试玩

**https://s2447920817-qiujiale.github.io/praise-the-fool/xiuxian-dungeon/**

> 若打不开：请到仓库 Settings → Pages 确认已开启（Branch = `main`，Folder = `/ (root)`）。

## 操作

- `WASD` 或 方向键 —— 移动
- 自动攻击附近的敌人
- 清空一间战斗房后，鼠标点击升级卡选择强化
- 任意键开始游戏

## 玩法

依次穿越 6 间地牢：

1. 迷途妖林
2. 邪煞幽境
3. 灵台清净处（奖励房）
4. 铁甲煞地
5. 煞气深渊
6. 终局 · 魔头现世（Boss）

每清空一间战斗房可获得随机强化（飞剑数量、攻速、暴击、护体、移速等），构筑流派斩杀魔头即可通关。

## 本地运行

直接双击 `index.html` 用浏览器打开即可，无需任何构建步骤或依赖。

## 文件

- `index.html` —— 入口页面（含全部样式）
- `game.js` —— 游戏主逻辑（约 1300 行，纯 Canvas 2D 绘制）
- `art-prompts.md` —— UI 素材的 AI 绘图 Prompt 包（修仙玉金风格）
